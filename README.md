# Walleros

Multiplayer FPS arena with full cross-platform play. Up to 20 players.

Procedurally generated maps, configurable weapon system with loadout customization, grenades, destructible environments, and AI bots for offline play.

### Unirse desde el navegador

El directorio de servidores en https://walleros-server-directory.vercel.app/ puede abrir una partida en Walleros con el botón **Unirse en Walleros**. Tras extraer el cliente, registra el protocolo una vez: ejecuta `register_protocol_windows.bat` en Windows. macOS registra el protocolo en el bundle de la app; abre Walleros una vez después de moverla a Aplicaciones. Los enlaces nunca incluyen contraseñas; el cliente las pide dentro del juego.

Descarga el cliente desde [este repositorio](https://github.com/hardraid/walleros_downloads).
