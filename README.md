# Walleros - Downloads

Multiplayer FPS arena game. Godot 4.6.3, GL Compatibility renderer.

## Latest Release

_Check `./tools/build_and_publish.sh` to generate builds._

## How to Download

1. Click the version folder (e.g., `v1.0.0/`)
2. Download the ZIP for your platform:
   - **Windows**: `Walleros_v*_windows_x64.zip`
   - **macOS**: `Walleros_v*_macos_universal.zip`
   - **Linux**: `Walleros_v*_linux_x64.zip`
3. Extract and run

## Dedicated Server

Server builds are in the same folder with `_server` suffix:

- `Walleros_v*_windows_x64_server.zip`
- `Walleros_v*_macos_universal_server.zip`
- `Walleros_v*_linux_x64_server.zip`
